# 📊 Student Report Card Management – Excel Project

## 📌 Overview

This project is an **Excel-based Student Report Card Management System** designed to organize student information, subject-wise marks, total marks, and average scores in a structured format.

The workbook also includes a formatted **CBSE-style Report Card** for presenting individual student performance.

## 🎯 Objectives

* Maintain student academic records in an organized manner.
* Store personal and academic information in a structured format.
* Calculate total marks and average marks.
* Generate a formatted student report card.
* Practice Excel data management, formulas, formatting, and report generation.

## 📂 Workbook Structure

The Excel workbook contains the following sheets:

### 1. Student Reports

Contains an individual student's report card with:

* Roll Number
* Student Name
* Father's Name
* Mother's Name
* Date of Birth
* Subject-wise marks
* Total marks
* Average/percentage-related information

### 2. Student Data

Contains the main student dataset, including:

* Roll Number
* Student Name
* Father's Name
* Mother's Name
* Date of Birth
* Hindi Marks
* Physics Marks
* Chemistry Marks
* English Marks
* Maths Marks
* Total Marks
* Average

### 3. Report Card Template

A formatted CBSE-style report card layout used to present student performance in a professional format.

## 📈 Key Calculations

The workbook calculates:

**Total Marks**

`Hindi + Physics + Chemistry + English + Maths`

**Average Marks**

`Total Marks ÷ Number of Subjects`

These calculations help summarize the academic performance of each student.
